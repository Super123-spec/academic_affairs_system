## 合规做法（交付时必须完成）

1. 随安装包一并提供本文件与各组件原始许可文本（可在 `pip show -f <包名>` 或各组件源码中获取）。
2. 不在宣传材料中暗示上述开源项目或作者对本软件背书。
3. 若替换/升级依赖版本，需重新核对本清单。

## 自行核查方式

```bash
# 列出当前环境全部依赖及其许可证分类
pip install pip-licenses
pip-licenses --format=markdown --with-urls

# 漏洞扫描（建议纳入发布流程）
pip install pip-audit
pip-audit -r requirements.txt -r requirements-prod.txt
```

> 建议：每次发版前执行一次 `pip-audit`，把结果归档到发布记录中。
