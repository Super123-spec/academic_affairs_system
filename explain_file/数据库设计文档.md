| 项目 | 内容 |
|---|---|
| 数据库 | MySQL（utf8mb4 / InnoDB） |
| 数据表数 | 28 张 |
| 版本 | v1.0（2026-10-30） |
| 依据 | `schema.sql`（唯一事实来源） |

---

## 一、设计原则

1. **存储引擎**：全部 InnoDB，支持事务与外键；
2. **字符集**：utf8mb4（兼容中文与 emoji）；
3. **外键与级联**：业务从属数据（如选课、申请、评价）随主数据删除级联清理；主数据被引用时用 `ON DELETE SET NULL` 保留历史；
4. **敏感数据**：`student.id_card` 身份证号 **AES-256-GCM 加密存储**（`enc:v1:` 前缀密文），读取时脱敏展示；
5. **并发安全**：名额抢占靠 `course_offering.selected_count` 原子更新 + `enrollment` 唯一约束；登录限流靠 `login_throttle` 主键行锁；
6. **安全辅助表**：验证码、限流状态入库（而非进程内存），以支持多 worker 部署。

### 3.2 组织架构

| college 学院 | code UNIQUE、name | — |
| major 专业 | college_id FK、code UNIQUE、name | college → major（级联删除） |

### 3.3 课程与排课

| 表 | 关键字段 | 关系 |
|---|---|---|
| course 课程 | code UNIQUE、name、credit、hours、type、college_id | college → course（SET NULL） |
| course_offering 教学班 | course_id、teacher_id、semester、max_count、selected_count、status、usual_ratio、exam_ratio | course/teacher → offering |

| course_schedule 排课 | offering_id、weekday、start/end_section、weeks、week_type、classroom_id | offering/classroom → schedule |

| 表 | 关键字段 |

## 四、关键约束与设计决策

| 决策 | 说明 |
|---|---|
| `enrollment` UNIQUE(student_id, offering_id) | 同一学生同一教学班只一条记录，配合事务回滚防止并发重复占坑 |
| `course_offering.selected_count` | 冗余计数，选课时 `WHERE selected_count < max_count` 原子 +1 防超卖 |
| `offering_class` 中间表 | 教学班可指定多个授课班级（合班），与选课分离 |
| `id_card` 加密列宽 255 | 容纳 `enc:v1:` + base64(nonce+ciphertext) |
| `must_change_pwd` 三表冗余 | 首次登录/重置密码后强制改密 |
| 外键级联策略 | 从属数据 CASCADE，主数据 SET NULL（保留历史可追溯性） |
