# 变更记录（CHANGELOG）

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [1.2.0] - 2026-11-04

修复「管理员新建学生后默认密码 123456 登录失败」与「班级统排课学生在教师成绩名单/导入中缺失」两个业务一致性问题。

### 变更

- **账号初始密码统一为 123456**：新建/批量导入学生、教师及管理员重置密码时，默认使用 `123456`
  （可用环境变量 `DEFAULT_INITIAL_PASSWORD` 覆盖），不再生成随机临时密码，也不再强制首次改密（按业务要求）。
  管理员指定自定义初始密码时同样直接生效；用户自行修改密码仍走强密码策略（≥8 位、含字母与数字、弱口令拦截）。
- **新建学生弹窗**新增「初始密码」输入框（默认 123456，仅新增时显示）；教师管理页同步。
- **重置密码**复选框由「文案 123456、后端随机密码」改为真正重置为 123456（学生、教师均一致）。

### 新增

- **班级课程继承（enrollment 同步）**：`enrollment_sync.py` 把「`offering_class` 指定到本班 + 本学期 +
  `course.type <> '选修'`（必修/通识/实践）」的统排课幂等地写成 `enrollment(status='已选')`，
  使教师端名单/成绩录入/成绩导入/模板与学生课表一致；选修课仍由学生自主选课，不自动加入。
- 自动同步时机：新建学生、批量导入学生、修改学生班级（撤销原班未录成绩的统排课、补齐新班）、
  新建开课并指定班级、修改开课授课班级。
- 管理员修复接口 `POST /api/admin/repair/sync-enrollment`：手动触发一次全量按班级补齐（幂等）。
- 教师端名单/成绩/模板/导入入口增加自愈：打开页面时自动补齐本班统排课学生，避免历史数据缺失。
- `upgrade_db.py` 增加「班级课程继承」幂等迁移步骤；`init_db.py` 初始化演示数据后同样执行继承同步。
- 学生 `退选` 增加守卫：统排课（本班指定、非选修）不允许退选，避免教师名单缺人。

### 修复

- 强制改密跳转：学生改密表单实际在 `profile-edit.html`，登录页原先统一跳 `profile.html`（无改密表单）导致卡住；
  现按角色跳转（学生→`/student/profile-edit.html?must_change=1`、教师→`/teacher/profile.html?must_change=1`）。
- 改密页密码提示文案「至少 6 位」与实际策略（≥8 位且含字母数字）不一致，已修正。
- `enrollment_sync.drop_stale_class_enrollments` 使用调用方 cursor 时误用参数名取 rowcount，导致转班撤销
  统排课记录时报 `NoneType has no attribute rowcount`，已修复为当前 cursor。

## [1.1.0] - 2026-10-30

安全加固版：补齐密码策略、PII 加密、审计与自动化测试。

### 新增

- **密码策略**：长度 ≥ 8、必须含字母与数字、拒绝常见弱口令（含 `123456`/`admin123` 等）。
- **强制首次改密**：账号表新增 `must_change_pwd`；导入/新建/管理员重置的账号首次登录必须先改密（服务端拦截写操作）。
- **管理员重置密码改为随机临时密码**：一次性展示给管理员，并强制该用户下次登录修改；同时记审计。
- **身份证号加密存储**：AES-256-GCM（密钥由 `SECRET_KEY` 经 HKDF 派生），列宽扩展为 `VARCHAR(255)`，
  兼容历史明文（`enc:v1:` 前缀标记）；返回前端时脱敏为 `520***********1234`。
- **登录审计**：登录成功/失败（含账号、IP、原因）写入 `operation_log`。
- **登录接口纳入 CSRF 校验**，关闭登录型 CSRF。
- **会话固定防护**：登录成功后重建会话。
- **改密后其他会话立即失效**：会话保存密码指纹，写操作时校验。
- **头像文件需登录访问**，避免未授权枚举。
- **Excel 导出防公式注入**：以 `=`/`+`/`-`/`@` 开头的文本自动加前缀。
- **pytest 自动化测试套件**（78 个用例）与 `pytest.ini`、`requirements-dev.txt`。

### 变更

- `upgrade_db.py` 新增两步迁移：补 `must_change_pwd` 列、加密历史明文身份证（自动扩列宽）。
- `requirements.txt` 新增 `cryptography==50.0.2`。

### 修复

- 身份证密文长度超过原列宽（`VARCHAR(30)`）导致的写入失败（已扩展为 `VARCHAR(255)`）。
## [1.0.0] - 2026-10-30

首个可交付版本：完成代码审查问题的修复，并补齐商用交付所需的工程化与安全基线。

### 新增

- `GET /health` 健康检查端点：返回 `status / db / version / semester`，数据库异常时返回 **503**，供负载均衡与监控探活。
- CSRF 防护（双提交令牌）：写操作必须携带 `X-CSRF-Token` 请求头，与 Cookie 中的 `csrf_token` 校验一致；
  登录、验证码接口豁免。前端 `api()` 封装与全部上传/导入请求已自动携带。
- 安全响应头：`X-Content-Type-Options`、`X-Frame-Options: DENY`、`Referrer-Policy`、`Permissions-Policy`、
  `X-Permitted-Cross-Domain-Policies`、CSP、HTTPS 下自动附加 `Strict-Transport-Security`。
- 接口响应 `Cache-Control: no-store`，防止成绩/个人信息被中间缓存。
- 可选强制 HTTPS：环境变量 `FORCE_HTTPS=1`（默认关闭，避免自锁）。
- 版本标识：新增 `VERSION` 文件，启动时读入并在 `/health` 中返回。
- 交付文档：`LICENSE`（专有许可）、`THIRD_PARTY_LICENSES.md`（开源组件清单）、`PRIVACY.md`（个人信息处理说明）、
  本变更记录。

### 修复（安全）

- 登录限流不再信任可伪造的 `X-Forwarded-For`，默认仅按 TCP 对端 IP 计数；
  反向代理部署通过 `TRUST_PROXY=1` 显式开启（读取代理注入的 `X-Real-IP` / XFF 最右项）。
- 限流记录表增加容量上限与过期清理，避免伪造 IP 造成内存无限增长。
- 冻结/停用账号的写操作立即失效（写请求前复查账号状态并清理会话）。
- 学籍异动审核通过后同步冻结/解冻账号，避免退学学生继续使用系统。
- 会话密钥：检测到占位符（如"请改成随机字符串"）或长度不足 16 位时忽略并自动生成随机密钥。
- 移除随包分发的 `.secret_key`；`SECRET_KEY` 仅由服务器本地生成或 `.env` 注入。
- 内联事件中的字符串改用 `escJs()` 转义，修复含单引号数据导致的脚本截断与存储型 XSS。
- 异常信息不再回显数据库细节（表名、约束名、SQL 片段），改为记录服务端日志 + 通用提示。
- 修改密码补充长度上限（bcrypt 72 字节截断）与"新旧密码相同"校验，并记录操作日志。

### 修复（数据完整性）

- 成绩录入/导入改为**增量更新**：缺列或空单元格不再清空已有成绩；仅更新提交的字段。
- 成绩写入、成绩导入、成绩比例调整均记录操作日志（含旧值→新值）。
- 修改成绩比例后自动按新比例重算存量总评与绩点；修复比例 `0` 被 `or` 吞掉的问题。
- 选课新增三项校验：仅限当前学期、上课时间冲突检测（星期/节次/周次，含单双周）、同学期同课程重复选修。
- 退课/重选增加状态守卫与 `rowcount` 校验，修复并发下名额超卖与虚增。
- 审核（通过/拒绝/撤销）增加状态守卫，消除并发重复执行副作用。
- 重修自动选课改为"先原子占名额再写选课记录"；学分替代不再覆盖已有及格成绩。
- 排课与考试安排新增教室/教师时间冲突检测。
- 开课编辑补齐比例合法性、容量下限、已有选课禁止更换课程等校验。
- 学生信息编辑改为只更新提交字段，避免误将 `is_frozen` 重置、`status` 置空。
- 申请类接口增加查重与参数校验；评教增加类型白名单并排除布尔值。
- 成绩单/GPA 统计按课程去重（取最高分），修复学分零除与 NULL 学分导致的 500。
- 专业分流校验专业存在性并锁定"已确认"状态。
- 未登录访问角色接口返回 401（原 403），补齐 400/415 的 JSON 错误处理。

### 修复（部署与运维）

- 依赖版本锁定（`requirements.txt` 固定 Flask 3.1.3 一组；`requirements-prod.txt` 升级为 gunicorn 23.0.0）。
- gunicorn 日志改为轮转（单文件 10 MB，保留 5 份），并限制仅信任本机代理的转发头。
- `init_db.py` 增加 `--yes` 二次确认，并在建库后重算 `selected_count` 保持与选课记录一致。
- `upgrade_db.py` 改为按 `schema.sql` 自动补齐缺失表、逐项容错并如实报告（不再声称"已回滚"）。
- `start.sh` 仅在依赖变更时安装，且首次初始化显式传 `--yes`。
- 当前学期改为环境变量 `CURRENT_SEMESTER` 可配（默认 `2025-2026-1`），跨学期无需改代码。
- 部署文档重写为纯命令流程（`部署文档.md`），去除真实 IP 与示例密钥，生产改用 gunicorn + 非 root + systemd 加固。

### 已知限制 / 后续计划

- 成绩"提交后锁定"状态机未实现（当前以审计日志追溯）。
- 学生删除仍为硬删除（级联清除选课/成绩），建议改为软删除。
- 专业分流缺少管理端审核页面（当前为"确认一次即锁定"）。
- 修改密码后不吊销其他设备会话（需服务端会话存储）。
- 身份证号仍为明文存储，未做加密与脱敏展示（见 `PRIVACY.md` 改进项）。
- 缺少自动化测试与 CI；建议后续补充 pytest 关键路径用例。
- 登录限流状态存放于各 worker 内存，多 worker 部署时阈值会被放大；规模化部署建议接入 Redis。
