# 个人信息处理说明（隐私政策）

> 本文件面向**部署方（学校/院系）**，用于满足《中华人民共和国个人信息保护法》(PIPL) 的告知义务，

## 二、我们收集哪些信息

| 类别 | 具体字段 | 是否敏感 | 来源 | 用途 |
|---|---|---|---|---|
| 身份识别 | 姓名、学号/工号、性别、出生日期 | 否 | 教务系统导入 | 账号标识、身份核验、名单与成绩单 |
| 证件信息 | 身份证号 | **是（敏感）** | 教务系统导入 | 学籍管理、成绩与证书归档 |
| 联系方式 | 手机号、电子邮箱、通讯地址、籍贯 | 部分敏感 | 学生自填/导入 | 通知送达、个人信息维护 |
| 教学数据 | 选课记录、成绩、绩点、评教内容、考试安排 | 否（但属学业信息） | 系统运行产生 | 教学管理、成绩归档、质量评价 |
| 账号安全 | 密码哈希（bcrypt，不可逆）、登录 IP、操作日志 | 否 | 系统运行产生 | 身份认证、安全审计、异常排查 |
| 图像 | 头像图片 | 否 | 用户上传 | 界面展示 |

## 三、处理的目的与法律依据

1. **履行教育管理职责所必需**（《个人信息保护法》第十三条第一款第（三）项）：学籍、选课、成绩、考试管理。
2. **敏感个人信息的单独同意**：身份证号属于敏感个人信息，须在首次采集前取得**单独同意**，
   并在系统内提供撤回同意的通道；未取得单独同意的，应停止采集与使用。
3. **安全审计所必需**：登录 IP、操作日志用于保障系统安全，符合第十三条第一款第（二）项。

## 四、存储与保护措施

- 存储地点：部署在学校自有服务器（境内）；不向境外提供。
- 保存期限：学籍与成绩数据按教育档案管理规定长期保存；登录日志、操作日志建议至少保存 **6 个月**（等保要求）。
- 保护措施：传输层加密（HTTPS）、密码 bcrypt 加盐哈希、数据库账号最小权限、按角色最小可见范围控制。
- **敏感字段保护（v1.1.0 已实现）**：
  1. 身份证号 **AES-256-GCM 加密存储**，密钥由 `SECRET_KEY` 派生，不随数据库备份外泄；
  2. 对外展示一律**脱敏**（`520***********1234`），接口不返回明文；
  3. 登录成功/失败均记录审计日志（账号、IP、时间）。
- **仍待改进项**：
  1. 尚未实现"谁查看了谁的敏感信息"的逐条访问审计（当前仅有登录与业务操作日志）；
  2. 管理员角色建议启用**二次验证**（短信/OTP）；
  3. 如需对外提供数据导出，应增加导出审批与留痕。

## 五、共享与委托处理

- 除法律法规要求或经个人信息主体另行同意外，**不向任何第三方提供**个人信息。
- 若使用第三方云服务（备份、监控、短信），须签订数据处理协议，并在本政策中列明第三方名称与处理范围。

## 六、个人权利与行使方式

| 权利 | 行使方式 |
|---|---|
| 查阅、复制 | 登录后在"个人信息"页面查看；成绩单可自行导出 |
| 更正 | 学生可在个人信息页修改联系方式；学号、姓名、身份证号等关键字段需联系教务处更正 |
| 删除 | 依据法律规定的删除情形，向教务处提出申请 |
| 撤回同意 | 敏感情形（如身份证号）可向教务处书面撤回 |
| 投诉举报 | 【教务处电话/邮箱】；也可向网信、教育主管部门投诉 |

响应时限：**15 个工作日内**答复。

## 七、未成年人信息

本校在校生一般为成年人；如涉及未满十四周岁未成年人，须取得**监护人同意**，并制定专项处理规则。

## 八、政策更新

本政策更新时将在系统登录页公示，重大变更将以站内公告方式通知。
