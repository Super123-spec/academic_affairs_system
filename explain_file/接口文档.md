| 项目 | 内容 |

---

## 一、通用约定

| 项 | 约定 |
|---|---|
| 协议 | HTTP/HTTPS，同源部署 |
| 数据格式 | `application/json`（GET 参数用 query string） |
| 认证 | 服务端会话 Cookie（`session`），登录后由后端维持 |
| CSRF | 写操作（POST/PUT/DELETE）必须携带请求头 `X-CSRF-Token`（值取自 `csrf_token` Cookie） |
| 响应结构 | 统一 `{ "success": bool, "message": str, "data": ... }` |
| 错误码 | 401 未登录 · 403 无权限/CSRF 失败 · 404 不存在 · 413 文件过大 · 429 限流 · 500 服务器错误 |

**鉴权标记**：`公开`（无需登录）· `登录`（任意已登录角色）· `学生` / `教师` / `管理员`（对应角色）· `超管`（管理员 + is_super）。

## 二、认证接口（auth）

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/auth/captcha` | 公开 | 签发一次性图形验证码，返回 `{token, image(base64)}` |
| POST | `/api/auth/login` | 公开 | 登录。参数 `{user_type, username, password, captcha_token, captcha_code}` |
| POST | `/api/auth/logout` | 公开 | 登出并清空会话 |
| GET | `/api/auth/me` | 登录 | 当前用户信息（含 `is_super`、头像） |
| POST | `/api/avatar` | 登录 | 上传/更新本人头像（multipart，≤5MB 图片） |
| GET | `/uploads/avatar/<filename>` | 登录 | 读取头像文件 |
| POST | `/api/auth/change-password` | 登录 | 修改密码，参数 `{old_password, new_password}` |

> 登录失败统一返回「用户名或密码错误」（防账号枚举）；IP 连续 5 次/账号连续 10 次失败触发限流 429。

## 七、接口示例

### 登录
```
POST /api/auth/login
Body: { "user_type": "student", "username": "2024001",
        "password": "***", "captcha_token": "…", "captcha_code": "AB3X" }
→ { "success": true, "must_change_pwd": false,
    "user": { "id": 1, "username": "2024001", "real_name": "张三", "user_type": "student" } }
```

### 选课
```
POST /api/student/course-select/enroll
Headers: X-CSRF-Token: …
Body: { "offering_id": 2 }
→ 成功: { "success": true, "message": "选课成功" }
→ 满员: { "success": false, "message": "该课程人数已满" }
```

### 审核
```
POST /api/admin/reviews/retake/1
Headers: X-CSRF-Token: …
Body: { "action": "approve", "remark": "同意" }
→ { "success": true, "message": "已通过" }
```
