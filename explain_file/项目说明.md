# 教务管理系统 —— 部署包

> 这是**可直接部署的纯净包**，不含开发文件、测试、本地配置。
> 详细说明见 `部署文档.md`，本文只给最短路径。

---

## 一、包里有什么

```
后端（8 个模块）
  app.py            入口：创建应用、注册蓝图、页面路由、错误处理
  core.py           基础设施：连接池、装饰器、通用函数、课表导出
  auth.py           认证与头像
  common.py         公共数据（元数据、公告、作息）
  student.py        学生端接口（31 个）
  teacher.py        教师端接口（12 个）
  admin.py          管理端接口（43 个）
  config.py         配置（自动加载 .env）

部署与数据库
  wsgi.py           WSGI 入口（gunicorn 用）
  gunicorn.conf.py  生产服务器配置
  init_db.py        首次初始化（建库建表 + 演示数据，需加 --yes 确认）
  upgrade_db.py     代码更新后补表（幂等，不清数据）
  schema.sql        28 张表结构
  requirements.txt        运行依赖（版本已锁定，需 Python 3.9+）
  requirements-prod.txt   生产依赖（gunicorn）
  .env.example      环境变量模板
  start.sh          Linux 一键启动脚本
  部署文档.md       完整部署文档

前端
  templates/        52 个页面（学生 24 / 教师 7 / 管理 20 + 登录页）
  static/           CSS / JS / 图片 / 头像目录（空）
```

## 二、最短部署路径（Linux）

```bash
# 1. 上传到服务器
scp -r 教务管理系统 root@服务器IP:/opt/

# 2. 进目录装依赖（Python 3.9+，推荐 3.11）
cd /opt/教务管理系统
dnf install -y python3-devel gcc gcc-c++        # 编译 bcrypt/cryptography 用
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -r requirements-prod.txt -i https://mirrors.aliyun.com/pypi/simple/

# 3. 配置数据库连接（必做）
cp .env.example .env
vi .env            # 改 MYSQL_PASSWORD、SECRET_KEY 两项

# 4. 初始化数据库（仅首次；脚本会二次确认，--yes 表示确认清空）
python init_db.py --yes

# 5. 启动
chmod +x start.sh
./start.sh
```

放行端口后访问 `http://服务器IP:5000`。

## 四、重要提醒

| 事项 | 说明 |
|---|---|
| **不要重跑 `init_db.py`** | 它会清空所有表。系统已上线后更新代码，用 `python upgrade_db.py` |
| **`.env` 必须配** | 不配就用代码默认值（MySQL 密码 `1234`），换机器会连不上 |
| **`.secret_key` 会自动生成** | 首次启动时生成，**不要提交到代码库、不要随包分发**，泄露会导致会话可伪造（分发包中已移除该文件） |
| **Python 版本** | 依赖版本已锁定，需 **Python 3.9+**（实测 3.11/3.13 均通过）；Flask 3.1.x 不再支持 Python 3.7 |
| **反向代理** | 部署在 Nginx 之后时，必须同时设置 `TRUST_PROXY=1`，否则登录限流会把所有用户当成同一个 IP |

## 五、安全与健壮性修复说明（2026-10-30）

本次针对代码审查发现的问题做了修复，主要项：

| 类别 | 修复内容 |
|---|---|
| 成绩数据 | 成绩录入/导入改为**增量更新**：缺列或空单元格不再把已有成绩清空；成绩写入与比例调整均记录操作日志；改比例后自动重算存量总评 |
| 选课 | 增加当前学期、上课时间冲突、同课程重复选修校验；退课/重选加状态守卫，杜绝并发下名额超卖或虚增 |
| 认证 | 登录限流不再信任可伪造的 `X-Forwarded-For`（改为 `TRUST_PROXY` 显式开启）；限流表加容量上限；冻结/停用账号的写操作立即失效 |
| 审核 | 审核与撤销加状态守卫，消除并发重复执行副作用；学籍异动通过后同步冻结账号；学分替代不再覆盖已有的及格成绩 |
| 排课 | 新增排课/考试教室与教师时间冲突检测 |
| 输入 | 统一 `get_json(silent=True)`、补 400/415 JSON 错误处理、参数范围与长度校验、异常信息不再回显数据库细节 |
| 前端 | 内联事件中的字符串改用新增的 `escJs()` 转义，修复含单引号数据造成的脚本截断/存储型 XSS |
| 部署 | 移除随包分发的 `.secret_key`；依赖版本锁定；gunicorn 日志轮转；文档去除真实 IP 与示例密钥、生产环境改用 gunicorn 且不以 root 运行 |
